# 라크 주간 보고 문서 작성 규칙

담당자는 지금까지처럼 **위키 아카이브의 클라이언트 폴더에 회차 문서를 쓰면 된다.**
외부 공유용 HTML은 그 문서를 읽어서 자동으로 만들어진다 — 따로 옮겨 적을 필요 없다.

아래는 변환기가 의존하는 최소 규칙이다. 지키지 않아도 변환은 되지만 섹션이 문단으로
뭉개질 수 있다.

## 1. 문서 제목

`YYMMDD` 로 시작한다. `260921 주간 보고` / `260921 1stCRM 주간 보고` 모두 인식된다.
이 숫자로 회차를 찾으므로 빠지면 `--doc` 으로 문서를 직접 지정해야 한다.

## 2. 머리말

```
**보고 기간:** 2026.09.21 ~ 09.27 (작성 기준일 2026.09.21)

**전체 요약:** 3~4문장.
```

- `보고 기간` 이 없으면 헤더에 기간이 비어 나온다.
- `전체 요약` 을 비워두면 변환 시 "요약 없음" 으로 경고한다. 대외 보고에서 요약은
  대표가 가장 먼저(때로는 유일하게) 읽는 부분이므로 비워두지 않는다.

## 3. 섹션은 `#` 제목으로

관례상 쓰는 제목: `지난주 완료 산출물`, `리스크 및 의존성`, `이슈 항목`,
`이번 주 계획`, `요청사항`. 제목 문구는 자유지만 아래 판정을 따른다.

| 본문 형태 | 결과 |
|---|---|
| 표 (문서 표 또는 마크다운 파이프 표) | 영역/내용/상태 표 |
| `-` 불릿 목록 + 제목에 리스크·이슈·의존 | 태그 달린 리스크 카드 |
| `1.` 번호 목록 | 강조 카드 (요청사항 등) |
| 그 외 문단 | 요약 카드 |

표의 3번째 열에 `완료` 가 들어가면 초록, 나머지는 파란 배지로 나온다.

## 4. 제품 단위 2단 구성

`# 제품명` 아래에 `## 지난주 한 일` / `## 이번주 할 일` 두 개를 두면 좌우 2단으로
렌더된다(지란지교 방식). 소제목이 세 개 이상이면 각각 별도 섹션이 된다.

## 5. 중첩 항목

번호 목록 아래 `-` 로 한 단 들여쓰면 하위 항목으로 들어간다. 두 단 이상은 지원하지
않으니 세 번째 단계가 필요하면 항목을 나눈다.

## 6. 안 써도 되는 것

- HTML, 색상, 글꼴 — 서식은 템플릿이 정한다.
- 대외 문체로 다듬는 일 — 발행 단계에서 처리한다. 사실만 적으면 된다.
- 내부 판단 근거나 추측 — 문서에 남기더라도 발행 시 걸러낸다. 다만 확실히
  대외로 나가면 안 되는 내용은 애초에 다른 문서에 쓰는 편이 안전하다.
