전체 요약

메타 데이터 연동과 구글 연동 QA 항목 반영을 완료해 배포했고, 대시보드 커스텀 화면에도 메타 데이터가 보이도록 적용했습니다. 대시보드 커스텀 QA는 계속 진행 중이며, 이번 주는 대시보드 커스텀 QA(v1.4.1, v1.4.2), 메타 연동 QA 반영, 카카오 모먼트 광고 연동을 진행합니다.

지난주 완료 산출물

  • 메타 데이터 연동 (개발 서버 배포)완료
  • 구글 연동 QA 항목 반영 (운영 환경 배포)완료
  • 메타 데이터 연동 대시보드 커스텀 반영 (개발 서버 배포)완료
  • 대시보드 커스텀 QA진행중

진행 현황

  • 대시보드 구조 정리 — 레거시 탭 추가 대신 커스텀 대시보드로 일원화하기로 결정했습니다. 이번 주 QA 결과를 바탕으로 재검토합니다.
  • 사용성 개선 — 커스텀 대시보드의 다중 기준 선택·열 묶음 구성에 대한 사용성 피드백을 반영해 UI/UX 개선안을 정리하고 있습니다.
  • 운영자 알림 — 이메일 알림 기능은 데이터 수집 파이프라인 구축 이후 적용할 예정으로, 차주까지 진행되는 카카오 모먼트 연동 범위에서는 제외됩니다.

요청주신 사항 확인

아래 요청사항을 확인했으며, 순차적으로 반영하고 있습니다.

  1. 카카오 개발자 권한 부여를 위한 지정 계정 초대
  2. 대시보드 커스텀 UI/UX 개선
  3. 테스트 케이스 1.4.1, 1.4.2 범위 이번 주 내 완료 및 전달

이번 주 계획

  1. 대시보드 커스텀 QA 항목 반영 (v1.4.1, v1.4.2)
  2. 메타 연동 QA 항목 반영
  3. 카카오 모먼트 광고 연동

요청사항

  1. 메타 연동 QA 항목을 전달해 주시면 반영하겠습니다.
  2. 정리해 드리는 커스텀 대시보드 UX 개선안을 귀사 개발팀에 전달 부탁드립니다.

향후 방향

  • 커스텀 대시보드 일원화에 리소스를 집중해 중복 개발을 줄입니다.
  • UX는 단계별 선택 UI, 프리셋 최소화, 가이드 강화 방향으로 개선합니다.
  • 에러 핸들링은 Kakao Moment부터 시작해 전체 서비스로 확장하고, 운영자 알림 체계를 구축합니다.
